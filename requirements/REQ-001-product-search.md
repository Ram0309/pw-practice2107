# REQ-001 Product search

As a guest shopper, I want to search for products by keyword so that I can quickly find what I want to buy.

Acceptance criteria:
- Searching for "laptop" shows "14.1-inch Laptop" in the results.
- A search term shorter than 3 characters shows the message "Search term minimum length is 3 characters".
- A search term with no matches shows "No products were found that matched your criteria."
- Each result shows the product name, price and an Add to cart button.
- Search results load fast and are user friendly.
